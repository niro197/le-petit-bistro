
## 13. Visuels actuellement intégrés

La version actuelle utilise ces fichiers locaux :

| Fichier | Usage | Format recommandé |
|---|---|---|
| `images/hero-bistro.webp` | Hero principal | 16:9, grand format |
| `images/plat-volaille.webp` | Carte de commande, volaille | 4:3 |
| `images/plat-gnocchi.webp` | Carte de commande, gnocchi | 4:3 |
| `images/ambiance-salle.webp` | Section histoire | 3:2 |
| `images/favicon.svg` | Icône du navigateur | SVG |

Les fichiers `.jpg` générés sont conservés dans `images/` comme originaux ; les fichiers `.webp` sont ceux utilisés par la page pour réduire le poids et accélérer le chargement. Remplacez-les uniquement si le client fournit des photos dont il possède les droits.
